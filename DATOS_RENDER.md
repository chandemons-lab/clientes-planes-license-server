# Evitar perdida de subusuarios y licencias

Este panel guarda los subusuarios y las licencias en `licenses.json`.

Si el servidor esta desplegado en Render sin disco persistente, los datos creados desde el panel pueden desaparecer cuando Render reinicia o redepliega el servicio. Eso explica que se borren de golpe las licencias y tambien la cuenta del subusuario.

## Opcion gratis: Supabase

1. Crea una cuenta gratis en Supabase.
2. Crea un proyecto nuevo.
3. Abre SQL Editor y ejecuta:

```sql
create table if not exists public.panel_data (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz not null default now()
);

create table if not exists public.panel_backups (
  id bigint generated by default as identity primary key,
  data jsonb not null,
  created_at timestamptz not null default now()
);
```

4. En Supabase, entra en Project Settings > API.
5. Copia:
   - Project URL
   - service_role secret key
6. En Render, entra en tu servicio > Environment y anade:

```text
SUPABASE_URL=https://TU-PROYECTO.supabase.co
SUPABASE_SERVICE_ROLE_KEY=TU_SERVICE_ROLE_SECRET
```

No pongas la `anon key`. Tiene que ser la `service_role secret key`, y no debe compartirse publicamente.

Con esas variables, el panel guarda los datos en Supabase y no se pierden aunque Render gratis reinicie.

Cada vez que el panel guarda cambios, tambien deja una copia anterior en `panel_backups`.

## Creditos de subusuarios

El admin puede crear subusuarios con creditos iniciales y cargar mas creditos despues.

- 1 credito = 1 mes de licencia.
- Si un subusuario crea una licencia de 12 meses, se descuentan 12 creditos.
- Si no tiene creditos suficientes, no puede crear la licencia.
- Al borrar un subusuario, tambien se borran sus licencias asociadas.

## Opcion con Render de pago

Si algun dia usas Render Starter, puedes usar Persistent Disk:

1. En Render, anade un Persistent Disk al servicio.
2. Montalo, por ejemplo, en `/var/data`.
3. En Environment, anade:

```text
DATA_DIR=/var/data
```

El servidor tambien reconoce `RENDER_DISK_PATH` si Render lo define.

Desde ahora, antes de sobrescribir datos, el servidor deja copias en:

```text
/var/data/backups
```

Si se ejecuta en local sin `DATA_DIR`, seguira usando el `licenses.json` de esta carpeta.
